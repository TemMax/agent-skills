Keep the cache in memory; move it to disk only for the offline mode

Reads take 2 ms from memory against 40 ms from disk, and the data rebuilds in under a second after a restart. One decision is yours: whether offline mode ships in this release (question 1).

How a read flows today

Options

A. Memory only Recommended

Fastest and simplest; the disk step goes away.

  • 2 ms reads, no blocking
  • Empty after a cold start (rebuilt in 0.8 s)

B. Memory and disk

Needed only if offline mode ships now.

  • Works without network
  • A second store to keep in sync
