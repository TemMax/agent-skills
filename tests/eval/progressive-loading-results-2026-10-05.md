## Реальное делегирование

Новый `--case handoff` запускает настоящий coordinator с сокращённым скиллом:
одна уже одобренная задача, один executor и один независимый reviewer через
штатный native runner, cap два дочерних вызова. Координатор останавливается
после summary, до интеграции и публикации.

Оба host загрузили полное тело своего `WORKFLOW.md` — оно подтверждено
в tool results, а замороженные файлы кандидата после прогона не изменились.
Оба native runner приняли результат; guard деления на ноль добавлен,
основная ветка и signing configuration сохранены. Проверки и ревью не удалены.
Это положительный execution probe; прежний semantic rejection не заменяется им.

## Сохранённые ошибки стенда и расход проверки

Первичная оценка Codex navigation неверно разрешала относительный путь к скиллу
из текущего репозитория вместо каталога фикстуры. По сохранённым трассам
`--recheck-loading` подтвердил точный кандидат без новых вызовов. Исходные
`outcomes.json` сохранены; исправленная оценка — `assessment-v2.json`.

Первый Codex handoff остановился без ревью: адаптер ошибочно посчитал
`codex sandbox` preflight модельным вызовом. Это ошибка стенда, не успешная
проверка. Исправлен passthrough без изменения команды и без расходования
модельного cap; новый живой прогон прошёл. Отдельная регрессия проверяет,
что preflight не мешает executor + reviewer уложиться в два вызова.

| Дополнительный probe | Все роли, input + output | Результат |

Суммарный захваченный usage этого этапа — 1 881 750 токенов, включая cache

задачи. `cost-control-live-analyze.py` включает coordinator и детей handoff;
навигационные пары сравниваются отдельно, без исключения ошибок из журнала.
