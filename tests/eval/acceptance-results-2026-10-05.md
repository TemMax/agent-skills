## Найденные и исправленные дефекты

1. Codex читал профиль относительно cwd/workspace symlink. Все четыре Codex
   entrypoint теперь задают базой физический каталог SKILL.md.
2. Claude после согласованной проверки предлагал лишнюю правку README. Узкая
   фаза заканчивается результатом и находками, без предложения нового этапа.
3. Claude спрашивал о дорогом проверяющем до решения продуктового конфликта.
   Сначала уточняются требования, затем выбираются роли. Требуемое premium
   approval сохранено.
4. Claude исключал AGENTS.md из узкого ревью. Правила репозитория обязательны;
   уже загруженные инструкции повторно читать не требуется.
5. Claude заново просил разрешить объём явно запрошенного нового планирования.
   Новый запрос уже разрешает заданный объём; нерешённые требования уточняются.

Исправлены ошибки стенда: Claude Skill может дописывать `ARGUMENTS` после точного
тела скилла; это не другая версия. При ручном чтении также обнаружены ложный
блокер «профиль отсутствует», пропуск repo rules и лишний вопрос разрешения.
Исходные outcomes сохранены, исправленные оценки — отдельные `assessment-v2.json`.
Они используются в [машинной сводке](acceptance-results-2026-10-05.json).
Неудачи не выданы за положительные повторения финального кандидата.

Все 19 попыток этого этапа, включая неудачные и повторённые после исправлений:
**4 378 746 захваченных токенов**, 47 логических CLI-вызовов. Cache reads включены.
Это цена закрытия проверки, не расход одной задачи и не обещание расхода лимита
подписки. JSON содержит каждую попытку, обычный input, cache creation/read и output.
Codex не сообщает cache creation отдельно. Предыдущие этапы в сумму не включены.

Потоковые Claude assistant events иногда показывают неполный output. Счётчик
теперь использует завершённый result usage только при совпадении всех трёх
input bucket с дедуплицированными root messages. Чужой cumulative/child scope не
подменяет root. Пересчёт выполнен без новых вызовов. Codex cumulative counters
сверяются с owned rollout; свежий session ID имеет отдельный baseline.
Без доказательства total остаётся незаявленным.

Уточнённая короткая progressive-loading A/B-пара: Claude 225 832 → 148 650
(−34,2%), Codex 171 256 → 137 261 (−19,9%). Это одна пара на host, не среднее.
Новые quality probes не являются A/B-оценкой экономии.

## Границы и доставка

Claude использует нормальный `--plugin-dir` и точное тело Skill injection/Read.
Codex — native workspace skill discovery с отключёнными плагинами: точные тела
чтений и frozen hashes подтверждены. Codex plugin hooks и пути discovery не
менялись, manifests изменяют только версии. Установленный Git-плагин и новая
сессия проверяются **после merge**, по требованию пользователя; cache,
marketplaces и установленные версии до этого не меняются.

4.8.1 существует только внутри reload fixture, checkpoint marker не меняет
продуктовую политику. Потеря контекста — настоящая свежая сессия, не автоматическая
compaction. Signing probe не проверяет финальную интеграцию: persistent config
остаётся true, executor использует разовый авторизованный `-c commit.gpgsign=false`.
Ранний unsigned/squash lint специфичен для Codex, одинаковая ранняя гарантия для
Claude не заявляется. Полный восьмиходовый duplicate-removal A/B и автоматическая
compaction не входят в обязательную matrix этого пакета и не запускались.

Raw evidence: `/private/tmp/final-acceptance-<host>-<case>-<n>`, включая frozen
expectations/snapshots, prompts, CLI args/status, streams, owned rollouts,
receipts, authorization и usage. Офлайн-проверки и упаковка фиксируются
в [итоге пакета](../../docs/analysis/2026-10-05-first-package-result.md).
