# Adversarial drift fixtures

The named case directories were authored by Fable 5 without prompt-authoring
context. Each retains a plan, transcript, and expected answer. Their stable
contracts and the three scenarios generated by [drift.sh](../../drift.sh) are
described in [EXPECTATIONS.md](EXPECTATIONS.md).

Use the [adjudication rules](../../../../docs/decisions/004-adversarial-evaluation.md)
when replaying cases. A false-positive fix must be checked against every true
positive; a transcript window must permit legitimate earlier completion without
accepting injected claims or unsupported scope cuts.
