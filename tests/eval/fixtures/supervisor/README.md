# Adversarial supervisor fixtures

The runnable F1–F4 branches are generated by
[supervisor.sh](../../supervisor.sh), using the compact
[contract checker](contract-check.py) stored here. See
[EXPECTATIONS.md](EXPECTATIONS.md) for inputs, verdicts, scoring, and limits.

The expectations also retain adversarial design constraints developed by Fable 5
without prompt-authoring context. Those constraints are not extra runnable
branches in this directory. Follow the
[adjudication rules](../../../../docs/decisions/004-adversarial-evaluation.md).
The current supervisor records reproduction mismatches as facts and uses the
four shipped violation classes; `forged-evidence` is no longer a verdict class.
